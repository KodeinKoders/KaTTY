:toc: macro
:toclevels: 2

Prebuilt https://ghostty.org[Ghostty] virtual terminal library (libghostty-vt) and its C headers, used by KaTTY for terminal emulation.

The dylib does not record the commit it was built from (`GHOSTTY_BUILD_INFO_VERSION_BUILD` is empty), so this file is the record.


== Provenance

[cols="1,3"]
|===
| Source | https://github.com/ghostty-org/ghostty[Ghostty], the `tip` tag
| Commit | `19a14dda3` (2026-10-13), "terminal: fix unsupp. ANSI modes as permanently reset in DECRQM (#14672)"
| Reported version | `0.1.0-dev`
| Build options | ReleaseFast, SIMD on, Kitty graphics on, tmux control mode off
|===

The library has no releases of its own, and its version is a placeholder.
The API is whatever the Ghostty commit above exports, and it is expected to change.
Always record the commit when updating.


== Layout

[source,text]
----
libghostty-vt/
├── include/ghostty/   <1>
│   ├── vt.h
│   └── vt/
└── lib/
    └── macos-aarch64/ <2>
        └── libghostty-vt.0.1.0.dylib
----
<1> The C headers, byte-identical to `include/ghostty/` at the commit above.
<2> One directory per `<os>-<arch>`.
Only macOS on Apple Silicon is built at the moment.

The dylib's install name is `@rpath/libghostty-vt.dylib`, while the file is named `libghostty-vt.0.1.0.dylib`.
Loading it by path, as the `ghostty-vt` module does, does not depend on the install name.


== Updating

. In a Ghostty checkout, check out the commit to use, and build the library:
+
[source,bash]
----
zig build -Demit-lib-vt -Doptimize=ReleaseFast
----
+
This needs Zig 0.16.0 or later, and writes the library to `zig-out/lib/` and the headers to `zig-out/include/`.
. Copy `zig-out/include/ghostty` over `include/ghostty`, removing headers that no longer exist.
. Copy `zig-out/lib/libghostty-vt.<version>.dylib` to `lib/macos-aarch64/`.
. Update the commit, date and version in the <<provenance>> table.
. Regenerate the Java bindings and the `GhosttyKey` enum with `ghostty-vt/jextract.sh`, and commit the result.
+
This needs https://jdk.java.net/jextract/[jextract] for JDK 25, either on the `PATH` or located by the `JEXTRACT` environment variable.
. Run `./gradlew build`.
