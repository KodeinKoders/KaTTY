They are not Gradle sources: the `terminal-themes` module packs them into its jar.

== Formats

The colors are stored as `Red Component`, `Green Component`, `Blue Component` and `Alpha Component` between 0 and 1, with a `Color Space`.
In this commit, 29 files use `P3`, 27 use `Calibrated`, and 147 do not say.
All the other files use `sRGB`.
KaTTY reads every component as sRGB, which is exact for the last two groups and an approximation for the first two.


== Updating

. Download the `schemes` directory and `LICENSE` of the new commit, and replace the ones here.
. Update the commit, the date, the number of files and the color spaces above.
. Run `./gradlew :terminal-themes:test`: it parses every file, so a file that the parser cannot read is reported.
